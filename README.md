# Personal Website Template
This is a small personal website that you can customize to your own needs.


## How to customize
Firstly clone the repository. Then open the file `/config/site.config.ts`. From there you can customize almost everything that the site has.

## How to run yourself

Run a development server with 

```bash
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) with your browser to see the site.
